# Contribution guidelines

Thanks for helping improve this list.

- One pull request per suggestion.
- Add the link to the most fitting section, at the bottom of that section.
- Use the format `- [Name](link) - Short description ending with a period.`
- Only add resources that are specifically about iPhone Duo or the iOS 27.1 foldable APIs.
- Libraries and apps should be open source and have a README that explains what they do.
- Check that the link works and does not point to a paywall or a sign-up page.
